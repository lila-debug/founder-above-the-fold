# Manual Drawer Instructions

## Mission

Maintain a monospaced Rube Goldberg-style walkthrough for Founder Above the Fold.
This repository explains the product; it does not contain or deploy the product.

## Locks

- Never add keys, tokens, email addresses, database URLs, `.env` values, or screenshots containing them.
- Never add product source code or a Vercel project link file.
- Point only to `lila-debug/founder-above-the-fold`, Vercel project `founder-above-the-fold`, `https://www.founderaccount.com`, and `/dashboard`.
- Use labelled parts, arrows, checks, warnings, and finished-build tests.
- Store tutorial state locally in the browser only.
- Require explicit founder approval before deploying or publishing this manual.

## Finished-Build Test

The tester must be able to answer, without coaching: Which repository? Which Vercel
project? Which URL? Which app route? Where does this environment slot belong?
