### Paste-ready submission description

Founders know their LinkedIn profile matters, but maintaining it becomes a second job: profile copy drifts, drafts restart from zero, and most automation tools introduce behaviour that founders should not trust with their accounts.

Founder Above the Fold is an owner-controlled LinkedIn operating system. It keeps approved headline, About and Experience copy in a versioned source-of-truth cabinet; moves drafts through an exact-revision British-English voice clamp; schedules only passed copy; publishes only through LinkedIn's official API rail; stores analytics only for the owner's app-published posts; and exposes the same safety rules through a typed MCP adapter.

The unusual part is the manual. It ships as an interactive product surface inspired by late-80s and early-90s IKEA, Meccano, Lego and Rube Goldberg machines. Users move through labelled parts, trigger a no-write mechanism, inspect live evidence lights, switch on beta-test mode, classify where they got stuck, save breakpoint evidence locally, and run a finished-build test. The manual is not written after the software. It is assembled beside every workflow so a stranger can operate the product without live coaching.

The public demo proves the core lock without asking for a LinkedIn connection: unsafe or non-British copy keeps the queue closed; a passing current revision unlocks a local demonstration queue; nothing is uploaded, scheduled or published. The private owner cabinet adds profile truth, content, queue, analytics, templates, export, MCP and the complete interactive assembly lane.

Founder Above the Fold deliberately does not scrape, automate DMs or connections, generate fake engagement, edit personal LinkedIn profile fields, or ask for a LinkedIn password. Profile changes remain an explicit human copy-and-paste step because the official personal-profile API does not provide those editing powers.

### Paste-ready maker note

I built Founder Above the Fold because I wanted founder visibility without surrendering control to scraping, auto-DMs or engagement theatre. The key design decision was to treat the operating manual as part of the product itself. Every mechanism ships with a visual assembly panel, and the complete manual behaves like a user-operated machine: parts drawer, triggers, live evidence lights, beta-test mode, breakpoint classification and a finished-build gauge.
